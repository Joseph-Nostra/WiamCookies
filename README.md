# 🍪 Wiam Cookies

A modern and elegant pastry portfolio website built for **Wiam Cookies**, showcasing handcrafted pastries, custom creations, and the brand's visual identity through a responsive and interactive web experience.

🌐 **Live Demo:** https://wiam-cookies.vercel.app/

---

## ✨ Features

* 🎂 Elegant pastry-focused design
* 📱 Fully responsive layout
* 🖼️ Product and pastry gallery
* 🍪 Showcase of custom creations
* 🎨 Modern visual identity
* ⚡ Fast and optimized Vite development environment
* 🧩 Reusable React components
* 📐 Responsive styling with Tailwind CSS
* 🔤 Type-safe development with TypeScript
* 🚀 Production deployment with Vercel

## 🚀 Getting Started

### Prerequisites

Make sure you have **Node.js** and **npm** installed on your machine.

Check your versions:

```bash
node -v
npm -v
```

### Installation

Clone the repository:

```bash
git clone https://github.com/Joseph-Nostra/WiamCookies.git
```

Navigate to the project directory:

```bash
cd WiamCookies
```

Install the dependencies:

```bash
npm install
```

---

## 💻 Development

Start the Vite development server:

```bash
npm run dev
```

The application will be available locally at the URL displayed by Vite, usually:

```text
http://localhost:5173
```

---

## 🏗️ Production Build

Create an optimized production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
